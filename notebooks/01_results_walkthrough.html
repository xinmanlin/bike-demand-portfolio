Results walkthrough¶

Hourly bike-sharing demand: interpretable count models and uncertainty under temporal shift

This notebook reads the already-computed results so it stays fast. To reproduce every number from the raw data, run python -m src.run_analysis in the project root, then python report/build_docs.py.

Scope. Task A = demand modelling conditional on same-hour weather. Task B = deployable forecasting using only calendar and lagged demand. The final 15% of the series is a held-out test period: it is not used for model or interval selection, which is done on validation data only.

Headline. Poisson GLM one-step-ahead test MAE 41.79 vs 168.89 (global mean), 66.48 (best naive, t-168h) and 55.21 (XGBoost, lag features). Best interval method by validation Winkler score: Split / Poisson-scaled.

5. Diagnostics and honest caveats¶

Lag-1 residual ACF = 0.73; mean demand rises 229.4 -> 281.6 -> 236.9 across calibration / validation / test. Exchangeability is unlikely to hold, so coverage figures are empirical measurements, not guarantees. See the technical report for the full limitations section.
